# Working rules
- Before editing any file, describe what you're about to change and why.
- For every line of code you add or modify, explain what it does and why
  it's needed. Put the explanation in your chat response, not as code comments,
  unless I ask for comments.
- Make changes in small steps (one file or one logical change at a time)
  so each diff is easy to review before I accept it.
- If you're unsure about my intent, ask before writing code.

-After each change, append an entry to `docs/claude-log.md` with:
  the date, my prompt (quoted), the files changed, and your line-by-line explanation.
